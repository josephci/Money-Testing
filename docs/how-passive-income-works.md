呢份係成個對話嘅總結。你第一句問「點樣自動每月賺 $10」,而家我可以答返一個當時答唔到嘅版本。

# 一、最核心嗰句

> **「被動收入」唔係一個你可以揀嘅選項。**
> **佢係一個轉換嘅終點。**

```
① 時間  →  錢          （主動。冇得跳）
② 錢    →  資產        （積累）
③ 資產  →  錢          （被動）
```

**冇本金嘅人,唔可能由零直接跳去 ③。**

所有真係有被動收入嘅人,唔係繼承咗 ①②,就係做過 ①②。冇第三條路 —— 睇落有嘅,通常係佢真正嘅收入嚟自賣你嗰個「第三條路」。

**呢個就係點解呢一整場對話,每條路最後都撞返同一堵牆。**

# 二、被動收入實際上得三個機制

## 1. 資本生息 —— 唯一真·被動

| | |
|---|---|
| $50/月 要幾多本金 | **約 $12,000–15,000**（4–5% 年息） |
| 維護 | 幾乎零 |
| 成功率 | 接近確定 |
| 你而家做唔做到 | ❌ 冇本金 |

**呢個係唯一真正「持續」而唔使你做嘢嘅收入。** 亦係唯一唔會因為 Google 改演算法、Amazon 改佣金、平台執笠而消失嘅。

## 2. 資產（產品 / 網站 / 內容）

| | |
|---|---|
| $50/月 要幾多本金 | **$12**（一個域名） |
| 要咩 | 時間 + **分銷** |
| 維護 | 中。唔更新會慢慢死 |
| 成功率 | **25–30%** |

**槓桿極高 —— $12 對 $15,000。** 呢個就係點解人人想行呢條。

**但代價係成功率跌到三成,而且瓶頸永遠係分銷。** 呢場對話已經證實咗：72% 成功嘅 indie hacker 話決定成敗嘅係分銷唔係產品;而零點擊搜尋（64.8%）啱啱好打殘咗最唔使面對人嗰條分銷路。

## 3. 經常性服務（訂閱）

| | |
|---|---|

| 維護 | 客會流失,要補 |

**數字最細（2 個人）,但要主動攞到嗰 2 個客。**

# 三、⭐「持續」呢兩個字,先係真正嘅分別

你問嘅唔係「被動收入」,係「**持續**被動收入」。呢個字揀得好,因為三個機制喺呢一點上差好遠：

| | 唔理佢會點 |
|---|---|
| **資本** | ✅ 繼續生息。真·持續 |
| **資產** | ⚠️ **會衰減**。價格過時、Google 改規則、Amazon 改佣金率（2020 年試過一夜腰斬）、平台執笠 |
| **服務** | ⚠️ **會流失**。客走咗要補返 |

**只有第一個係真正唔使你做嘢都會持續。**

其餘兩個嘅正確講法唔係「被動」,係「**低維護**」—— 每月幾個鐘,唔係零。

> 呢個亦係點解「一次過搞掂,之後永遠有錢收」呢種說法,喺資產同服務上係假嘅。

# 六、所以,持續被動收入點嚟

**答案係三句：**

1. **短期唔會有。** 冇本金 = 一定要有一段唔被動嘅時間。呢個冇得繞
2. **中期靠資產。** $12 + 時間,成功率三成。你已經有一個砌好晒嘅,等緊 3 個鐘
3. **長期只有資本係真·持續。** 而本金嘅唯一來源,係前面兩樣賺到嘅錢

**而三樣全部由同一個動作開始：做完嗰 8 到 10 題。**
