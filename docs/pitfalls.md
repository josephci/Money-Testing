# 陷阱：賺到 ≠ 攞到手

好多人「賺咗 $10」但一蚊都攞唔到。以下係細額收入獨有嘅坑。

---

## 1. 提款門檻（最大的坑）

平台唔會夠 $10 就打俾你，通常要儲到某個數：

| 平台 | 提款門檻 | 每月 $10 要等幾耐 |
|---|---|---|
| Google AdSense / AdMob | US$100 | **10 個月** |
| Amazon KDP（電匯）| 視乎地區，通常 $100 | 10 個月 |
| 多數頻寬分享 App | ~US$20 | 2 個月 |
| Gumroad | 約 US$10 | 1 個月 |
| Stripe | 冇門檻，按 payout schedule 過數 | 即時 |

**啟示**：如果你想真係每月見到錢入帳，**直接收款（Stripe / Lemon Squeezy）＞ 廣告分成**。

---

## 2. 手續費食你幾多

### 低單價 = 手續費比例爆高

Stripe 標準費率 2.9% + $0.30：

| 售價 | 手續費 | 實收 | 蝕咗 |
|---|---|---|---|
| $3 | $0.39 | $2.61 | **13.0%** |
| $10 | $0.59 | $9.41 | 5.9% |
| $30 | $1.17 | $28.83 | **3.9%** |
| $50 | $1.75 | $48.25 | 3.5% |

**$0.30 嘅固定費係殺手。** 賣 $3 嘅嘢，成 10% 俾咗個固定費。

### 三個直接省錢嘅決定

1. **收年費，唔收月費** — $30/年 vs $3/月 × 12：手續費由 $4.68 減到 $1.17，一年慳 $3.50（即係你目標嘅 1/3 個月）
2. **賣少啲、賣貴啲** — 1 件 $12 ＞ 4 件 $3
3. **睇清楚跨境/貨幣兌換費** — 收美金入港元戶口，銀行可能再食 1–3%

### 其他平台抽成（大概數，會變）

- Gumroad：約 10%
- RapidAPI：約 20%
- Amazon KDP：$2.99–9.99 區間版稅 70%，其他價位 35%
- App Store / Play Store：15–30%
- GitHub Sponsors：GitHub 唔抽

---

## 3. 隱藏成本會食晒你嘅利潤

年收入得 $120，好易蝕本：

| 項目 | 年費 | 佔你年收入 |
|---|---|---|
| Apple 開發者帳號 | US$99 | **83%** ❌ |
| 域名 | ~US$12 | 10% |
| 付費 hosting（如果超出免費 tier）| $60–240 | 50–200% ❌ |
| Chrome Web Store 上架 | US$5（一次過）| 4% |

**規則：起步階段所有嘢用免費 tier。** Cloudflare Workers、Vercel、Netlify、Fly.io、Supabase 嘅免費額度對一個細工具嚟講綽綽有餘。有客俾錢先好升級。

**Apple 開發者帳號基本上排除咗 iOS app 呢條路** —— $99 成本對 $120 年收入，第一年淨賺 $21。

---

## 4. 稅

- 香港：一般嚟講海外投資收益、銀行存款利息唔徵稅；但**經營業務嘅收入**（賣產品、賣服務）屬利得稅範圍
- 金額細唔代表冇申報責任 —— 唔確定就問會計師，唔好靠網上討論區
- 美國平台（Gumroad、Amazon、Google）會叫你填 **W-8BEN**：填咗可以按稅務協定減免預扣稅，唔填隨時被扣 30%
- 保留所有收入記錄同平台月結單

⚠️ 呢度唔係稅務意見，只係提你有呢件事要處理。

## 5. 騙局識別

一睇到呢啲，即刻走：

- 🚩 **「保證回報」、「穩賺」、「零風險高回報」** — 世界上冇呢支歌仔唱
- 🚩 **要你先俾錢** — 培訓費、入會費、押金、「解鎖提款」手續費
- 🚩 **拉人頭有獎** — 傳銷結構，最後嗰批人一定輸
- 🚩 **幫人收錢再轉出去** — 呢個叫 money mule，**係刑事罪行**，唔好諗
- 🚩 **要你嘅銀行密碼 / OTP / 私鑰** — 任何理由都唔可以俾
- 🚩 **時間壓力**（「今日截止」、「淨返 3 個名額」）— 專門用嚟令你唔經思考

### 睇落合法但唔值得做嘅

| 「機會」 | 點解唔好 |
|---|---|
| 睇廣告 / 打碼 / 掛機賺錢 | 時薪低過 $1，好多平台夠數就封你戶口 |
| 網上問卷 | 時薪 $1–3，而且做到一半話你「唔符合資格」 |
| 微任務平台 | 唔自動，純粹用時間換極少錢 |
| 頻寬分享 App | 收入極低、多數違反 ISP 條款、你條 IP 被人拎去做出口 |

**核心判斷**：如果一件事「唔使技能、唔使本金、人人做得、又話賺到錢」—— 咁全世界都會做，佢就唔會賺到錢。有錢賺嘅嘢一定有門檻：技能、本金、時間、或者品味。

---

## 6. 心理陷阱

- **沉沒成本** — 花咗 40 個鐘個 project 都係冇人用，止蝕好過死撐
- **無限打磨** — 未出街之前加 feature 全部係浪費，出街先算
- **收入 ≠ 利潤** — 記得計埋你花咗幾多個鐘。40 個鐘換一年 $120，時薪 $3；但如果佢真係之後全自動咁跑十年，就係另一回事
- **$10 唔係終點，係驗證** — 賺到第一個 $10 嘅價值唔喺 $10，喺於**證明咗有人肯俾錢**。由 $0 到 $10 難過由 $10 到 $100
