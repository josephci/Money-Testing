# ⚠️ 數學上 work,但你做唔得嗰個

## 體育博彩套利（arbitrage betting）

> 🔧 **更正**：本文第一版寫「每注 5–15%」係錯嘅。
> **純套利（arb）實際每注 0.5–3%,大部分時間 1–2%。**
> 嗰啲 5–15%、70–80% 嘅數字嚟自 **matched betting —— 即係用莊家送嘅免費注碼去轉現金**,係另一回事（一次性、每個戶口用完即止）。

### 原理：隱含機率加埋少過 100%

歐洲盤換算隱含機率 = `1 ÷ 賠率`。

**同一間莊家度永遠 arb 唔到**,因為佢一早收埋自己嗰份：

```
莊家 A 開：X 1.90 · Y 1.90
1/1.90 + 1/1.90 = 1.0526  →  105.26%
                              ↑ 多出嗰 5.26% 就係佢利潤(overround)
```

**兩間莊家睇法唔同嗰陣先有窿：**

```
莊家 A：X 2.05     莊家 B：Y 2.00
各取最高：1/2.05 + 1/2.00 = 0.4878 + 0.5000 = 0.9878  →  98.78%
利潤 = 1 ÷ 0.9878 − 1 = 1.23%
```

注碼按隱含機率比例分,總本金 $10,000：

| 落邊度 | 計法 | 注碼 | 收返 |
|---|---|---|---|
| A 買 X @2.05 | 10000 × 0.4878/0.9878 | $4,938 | $10,123 |
| B 買 Y @2.00 | 10000 × 0.5000/0.9878 | $5,062 | $10,123 |

**邊個贏都係收返 $10,123,淨賺 $123。** 冇預測成分。

### 個窿邊度嚟

| 來源 | 解釋 |
|---|---|
| **反應速度差**（最大宗） | 有消息(傷出、正選、紅牌),sharp book 幾秒改盤,soft book 慢 30–90 秒 |
| 客群唔同 | 西班牙莊家啲錢全押皇馬,被迫縮賠率;英國莊家冇呢個壓力 |
| 優惠／免費注 | 5–15%+ 嘅真正來源,但一次性 |

> ⚠️ 睇清楚第一行 —— **佢同加密貨幣搬磚係同一個結構：鬥快。**

### 點解實際上唔得

先計流水：每注 1.5%,交 Pro($20/月)要每月約 **$1,350** 流水;Max 20× 要 **$13,300**。數字唔嚇人,但佢死喺呢五樣：

1. **限注／封戶（最致命）** —— 通常**幾星期內**被限到每注 $20。上限由「有幾多 arb」變成「佢俾你落幾多」
2. **Palpable error 可事後作廢** —— 莊家 T&C 寫明開錯盤可隨時取消,贏咗照取消。而**最靚嗰啲 arb 正正就係開錯盤**。一邊被 void,另一邊即刻變裸倉,同時被標記為 sharp
3. **Leg risk** —— 落完第一注,轉去第二間賠率已經走咗,你得一半倉
4. **兩間結算規則唔同** —— 球員退賽、加時算唔算,「必賺」變兩邊都輸
5. **資金分散 + KYC** —— 錢攤喺十幾個戶口,提款要驗身份

### 點解佢不可能 auto

> **莊家整套防禦機制,核心就係偵測自動化行為。你寫 bot 落注 —— 封得最快嗰個就係你。**

實際做法要扮散戶：注碼唔整齊、間中落正常波、隔一排先提款。即係話**「賺錢」嗰部分完全喺於人手偽裝**,唔喺於搵 arb（scanner 月費幾十蚊就買到）。

**所以佢喺「自動搬磚」呢個分類入面,得個名。**

### ❌ 但香港做唔得

《賭博條例》(第 148 章) 第 8 條：向非認可收受賭注者投注 —— **不論賭注喺香港定境外收取** —— 即屬犯罪,最高罰 **$30,000 + 監禁 9 個月**。用海外「合法註冊」網站一樣中招。

**結論：原理值得明（下面用得著）,但呢條路跳過。**
