# 搬磚做量 vs 信息差 —— 深入研究

（2026-07 查證）

---

## 一句總結

| 方向 | 結論 |
|---|---|
| **搬磚做量（自動化跑量）** | ❌ **呢個形態唔存在。** 邏輯上自相矛盾,而且平台明文封殺 |
| **搬磚做量（人手,積少成多）** | ✅ **可行,而且係我哋傾過所有方法入面最穩陣嗰個** —— 但完全唔自動 |
| **信息差** | ✅ **你嘅直覺完全啱。** 而且你已經整緊嘅嘢就係佢,只係之前唔係咁叫 |

# 方向一：搬磚做量

## ⭐ 一條定律,解釋晒成件事

> **能夠自動化嘅嘢,已經被自動化咗,所以唔值錢。**
> **仲值錢嘅嘢,係因為要人判斷 —— 而要人判斷,就自動化唔到。**

呢個唔係悲觀,係定義。如果一件工作可以由 script 完成,平台老早自己跑咗,唔會俾錢你。

**你想要嘅「自動化跑量賺錢」,喺呢個定義下係自相矛盾。**

## 平台實際點做

唔止係理論。查到嘅實況：

| | |
|---|---|
| **MTurk 政策** | 用 bot / script 完成任務 → **停權、終止帳戶、餘額沒收** |
| 點解咁嚴 | 有研究發現 **三分一以上** MTurk worker 用緊 AI 做嘢,資料質素崩潰 |
| Clickworker | Trustpilot 由 4 分以上**跌到 2.6**,任務荒 + 大量驗證封號 |

> MTurk 容許 script 幫你**搵**任務、**預覽**任務。但**唔可以代替人做判斷**。
> 呢條界線好清楚 —— 而你想要嘅正正係越界嗰邊。

## 但係 —— 人手版本係真嘅,而且係最穩陣嗰條路

如果你肯接受「唔自動」,呢個方向有個好實在嘅答案：**AI 訓練資料標註。**

| 平台層級 | 時薪 |
|---|---|
| 初級標註（Appen、Toloka） | $10–15 |
| **中層（Outlier、DataAnnotation）** | **$20–40** |
| 專家級 RLHF（Mercor、Scale） | $75–250（要學位 / 專業資格） |

2026 年 AI trainer 全國平均 **$31/小時**。

### 換算你嘅目標

> **$50/月 ÷ $25/小時 = 每月做 2 個鐘。**

**呢個係我哋傾過所有方法入面,達到 $50/月機會最高嗰個 —— 我估 70–80%。**

主要風險唔係做唔到,係**入唔到平台**（要過測試同背景審核）。

⚠️ 老實話：實際時薪會低過標價,因為搵任務、篩選、無償測試嗰啲時間唔計錢。

### 但佢完全唔符合你想要嘅嘢

- ❌ 零自動化
- ❌ 唔累積,停手即停錢
- ❌ 唔係資產
- ✅ 但**最穩陣**,而且 2 個鐘就達標

**我唔會叫你一定要做。但你問「呢個方向可唔可行」—— 答案係：人手版可行得好,自動版唔存在。**

## 順便釘死一個誘惑

「大量出 AI 內容頁去跑流量」—— **2026 年 3 月之後死得好徹底。**

Google 嘅 **scaled content abuse** 政策點名三種違規：

1. 大量 AI 生成頁面而冇編輯審核
2. 純粹「模板 + 變數替換」跑量
3. **聚合網站但冇喺原始資料之外加任何脈絡**

罰則：**排名一夜跌 60–90%**。2026 年 3 月嗰次更新 19.5 個鐘就跑完,史上最快。

# 方向二：信息差 ⭐

**你呢個直覺係啱嘅。而且我要講清楚：你已經整緊嘅嘢就係佢。**

## 但要分清兩種完全唔同嘅玩法

### ❌ 做套利（自己買賣賺差價）

| 查到嘅實況 | |
|---|---|
| 起步資本 | **$500–1,000** |
| 實際淨利率 | **10–20%**（唔係吹嗰啲 50%） |
| 折算時薪 | **$6–12/小時** |

**你零本金,呢條路直接封死。** 而且就算有本金,時薪都低過標註工作。

### ✅ 賣信號（話俾人聽個 gap 喺邊）

**零本金。你唔使買貨,你賣「知道」。**

呢個就係：

- 監察 + 通知服務（$29/月 × 2 個客）
- 比價表（電池站）
- 招標 / 資助公告聚合

**同樣係信息差,但你賺嘅唔係差價,係「幫人慳返搵嗰個 gap 嘅時間」。**

## ⭐ 最重要嘅一點：護城河唔係秘密,係組裝成本

呢個係整個方向嘅核心,值得慢慢睇：

> **啲資料全部係公開嘅。**
> 你嘅優勢唔係「你知人哋唔知」。
> 你嘅優勢係 —— **佢散落喺 40 個來源、格式唔同、日日變,而冇人肯砌埋佢。**

呢個模式嘅好處：

| | |
|---|---|
| 要唔要本金 | ❌ 唔使 |
| 可唔可以自動化 | ✅ **可以 —— 呢度先係「全自動」真正成立嘅地方** |
| 護城河會唔會消失 | ❌ 相反,**歷史數據會令佢越嚟越深** |
| 要唔要面對人 | ❌ 唔使（如果做比價站） |

**呢個就係你講嘅「全自動信息差」—— 而佢真係存在。**

## ⚠️ 但有條紅線要識

2026 年 3 月 Google 明文點名：**「聚合網站但冇喺原始資料之外加任何脈絡」= 違規,跌 60–90%。**

**純粹抄埋一齊 = 死。抄埋一齊 + 加分析 = 生。**

查到嘅原文話明,仲活得好嘅係：

> *"comparison tools with live pricing"*、*"directories with verified listings"*、*"pages built on unique, structured data"*

電池站啱啱好喺生嗰邊,因為佢**唔係**淨係列價：

- 用標稱電壓重新計算（**原始資料冇呢個數**）
- 多支裝除總能量（**原始資料冇呢個數**）
- 「4 隻其他每蚊俾多啲電,最抵嗰隻平 18%」（**呢句係分析,唔係轉載**）

⚠️ **但我要老實講**：39 個型號頁比較接近條線。佢哋救得返係因為每版嗰句比較分析係計出嚟嘅。**如果你將來加型號,唔好淨係加行數據 —— 一定要保住嗰句分析。**

# 兩個方向其實會合流

你講嘅兩樣嘢,喺一個地方交匯：

```
       搬磚做量                     信息差
   （大量處理資料）              （知人所不知）
            \                      /
             \                    /
        「大規模自動組裝散落嘅公開資料,
          加上人哋計唔到嘅分析」
                    ↓
        電池站 · 監察服務 · 招標聚合
```

**你嘅兩個直覺都指向同一樣嘢,而我哋已經整咗一個出嚟。**

分別只係：唔係「搬磚賺人工」,係**「搬磚砌成一個資產」**。

# 一個你未考慮過嘅新選項：賣數據本身

查嘅時候發現嘅,值得提。

**Data marketplace** —— 你將砌好嘅資料當產品上架,唔使做面向消費者嘅網站。

| | |
|---|---|
| 平台 | AWS Data Exchange、Snowflake、Databricks、Datarade、Kaggle、Bright Data |
| 抽成 | Databricks Marketplace **賣家收 90%** |
| 趨勢 | 由「賣一次過嘅資料集」轉向 **Data-as-a-Service（訂閱制持續更新嘅資料流）** |
| 需求動力 | **AI 訓練需要大量專門資料集**,需求上升 |

**點解啱你**：

- ✅ 完全零社交,平台帶買家
- ✅ 一次砌好,之後全自動
- ✅ 同你已經砌嘅嘢**共用同一份資料**

**點解要保守**：

- ❌ 呢啲平台偏企業客,電池價格數據太窄
- ❌ 好難預測,可能完全冇人問

**我估機會 10–15%。** 但佢嘅邊際成本近乎零（同一份資料多上一個架),值得順手做。

## 睇到個取捨未

**穩陣 ↔ 自動,係反比。**

- 最穩嗰個（標註）**完全唔自動**
- 最自動嗰個（電池站）**最唔穩**

**冇一個係「又穩又自動」。** 如果有,全世界都做咗,佢就唔會再賺錢 —— 呢個又返返去最頂嗰條定律。

# 我嘅建議

**兩邊一齊行,分工唔同。**

### 短期現金：AI 資料標註

- 去 DataAnnotation / Outlier 申請
- **每月 2 個鐘 = $50**
- 唔係資產,但佢**即刻**有錢,而且成功率最高
- 呢筆錢嘅作用係：**買時間同耐性**,等下面嗰樣嘢慢慢跑

### 長期資產：信息差 + 全自動

- 電池站已經砌好,3 個鐘試一試
- 記住條紅線：**加分析,唔好淨係聚合**
- 順手上一次 data marketplace

### 唔好做

- ❌ 自動化跑 microtask —— 封號 + 沒收餘額
- ❌ 大量出 AI 內容頁 —— 3 月更新後跌 60–90%

你問「呢兩個方向可唔可行」。老實答：

**「自動化搬磚」係一個唔存在嘅嘢** —— 唔係你搵唔到方法,係佢邏輯上唔成立。
