# 人人都用 AI 接單,咁我仲有咩優勢？

（2026-07 查證）

---

## 先講：你嘅擔心係啱嘅,而且情況比我上次講嘅差

我上次估 Fiverr 路線「6 個月做到 $50/月」機會 **60–70%**。查完之後,**呢個數字太高。**

實際數據：

| 2026 數據 | |
|---|---|
| **Fiverr 活躍買家** | **按年跌 13.6%** |
| Upwork 活躍客戶 | 一年少咗約 47,000（-6%),股價 YTD -56% |
| 平台上嘅網頁開發者 | **6 年內變成 4 倍** |
| 受影響最重嘅類別 | logo、寫文、**基本 coding**、**簡單資料輸入** ← 正正係我叫你做嗰啲 |

Wharton 嘅研究（Manav Raj 教授）量度到：**自 2022 年底 ChatGPT 出咗之後,寫作、翻譯、基本編程嘅自由職業需求有實質下跌。**

**即係：買家少咗,賣家多咗四倍,而你要入嗰個類別正正係被壓價最勁嗰個。**

### 修訂後嘅機會

| | 舊估計 | **修訂** |
|---|---|---|
| 6 個月做到 $50/月 | 60–70% | **35–45%** |

我唔應該俾你一個未查過嘅數字。

---

## 但係 —— 有一句話係整件事嘅答案

搜尋結果入面有一句,值得抄低：

> **「The first draft is becoming free. Accountability is not.」**
> （初稿正在變成免費。承擔責任冇。）

呢句就係你嘅優勢喺邊。

---

## 你嘅優勢唔係「識做」,係「唔做」

**能力已經商品化。** 你識做、佢哋都識做、AI 幫緊全部人。所以能力唔再係分別。

分別喺三個**AI 助手用家系統性做唔到**嘅位：

### 1. ⭐ 識得推單

**呢個係最大嘅優勢,而且反直覺。**

大部分用 AI 接單嘅賣家係咁：

```
客傳 URL → 問 AI「做唔做到？」→ AI 話「做到!」→ 接單
    → 發現個網站係 JavaScript 砌 / 有反爬蟲 / 要登入
    → 交唔到貨 → 遲交 → 差評 → 帳戶玩完
```

**AI 傾向講「做到」。佢冇真係去 fetch 過嗰版。**

而你有 `--inspect` —— 你係**真係去攞過嗰版返嚟**,兩分鐘之內知：

- robots.txt 畀唔畀
- 抽唔抽到重複結構（抽唔到 = JS 砌,做唔到）
- 每欄實際抽到咩

**喺一個人人過度接單嘅市場,識得講「呢單我做唔到」本身就係競爭優勢。**

推單成本係零。硬接一單交唔到嘅,成本係你成個帳戶。

### 2. 開個檔案望一眼

AI 出嘅嘢**似樣但會靜靜哋錯**：

- 有一欄全部空咗（selector 打錯）
- 重複行（分頁兜返轉頭）
- 攞咗個連結文字「details」而唔係個 URL

用 AI 嘅賣家好多係「AI 出咗就直接傳俾客」。

工具會幫你捉頭兩樣（空欄警告 + 自動去重複),但**第三樣要人眼**。

呢個就係 START-HERE 第 ⑥ 步。**三分鐘,而佢係你同一個爛 script 之間唯一嘅分別。**

### 3. ⭐ 長期負責 —— 真正嘅護城河

呢個先係最重要嗰個,亦都解釋咗點解「轉月費」唔止係賺多啲錢嘅技巧。

| | 一次性抓取 | 每星期幫你更新 |
|---|---|---|
| AI 做唔做到 | **做到** | 做到一次 |
| 商品化咗未 | **已經** | **未** |
| 要咩 | 一段 code | **一個六個月後仲喺度嘅人** |
| 個網站改版嗰陣 | 客自己孭 | **你修** |

**一次性交貨係商品。持續可靠唔係。**

搜尋結果亦講到市場正在分層：**按鐘計嘅商品工作跌價,賣「結果」嘅加價。**

所以你嘅定位唔應該係：

> ❌ 「我幫你抓一版網頁」（商品,同幾千人爭)

而係：

> ✅ 「你唔使再理呢份資料,我幫你保持最新」（結果,要人負責)

---

## 第四個優勢：仲留喺 Fiverr 嘅買家,係篩選過嘅

呢個角度好重要。

**任何識得叫 AI 自己做嘅人,已經自己做咗。** 佢哋唔會落單。

所以而家仲會落單嘅人,係以下三種：

1. **唔知自己可以叫 AI 做** —— 佢哋唔係技術人
2. **試過,爛咗** —— AI 出咗段 code,佢跑唔到,又唔識 debug
3. **唔想孭呢件事** —— 佢知自己搞得掂,但唔想每個月處理

**呢三種人都唔係買 code,佢哋買「唔使再諗呢件事」。**

而呢樣嘢,你俾到,一個 AI 生成嘅一次性 script 俾唔到。

> 呢個同我哋之前傾「佢自己做到點解要買你」係同一條邏輯 —— 而喺 AI 時代,**呢條邏輯係更強,唔係更弱**,因為識自己做嗰批已經走晒。

---

## 三個要調整嘅做法

### 1. 由第一日起就講「可靠」,唔好講「平」

Gig 描述唔好同人鬥平（你鬥唔過)。要突出：

- **「我會先幫你檢查,做唔到會即刻話你知」** ← 呢句而家係核心賣點,唔係客套話
- 「24 小時內交」
- 「我唔會抓要登入嘅站、唔會抓個人資料」

**「我唔做啲乜」係信任訊號。** 喺一個人人講「乜都做到」嘅市場,呢個好突出。

### 2. 更快推月費

原本我叫你交貨之後先提。**改成：第一單交完就提。** 唔好等第二單。

因為一次性單價會繼續跌,而月費客係你唯一唔受壓價影響嘅收入。

### 3. 唔好只靠 Fiverr

Fiverr 買家跌緊 13.6%。**同時擺喺 Upwork**（同一份 gig 內容),兩邊都放。成本係多開一個帳戶。

## 老實嘅結論

| | |
|---|---|
| 你嘅擔心 | ✅ **成立**,而且有數據支持 |
| 我上次個估計 | ❌ 太樂觀,已由 60–70% 改成 **35–45%** |
| 能力係咪你嘅優勢 | ❌ 唔係,已商品化 |
| **咁咩係** | ✅ **識推單、會核對、肯長期負責** |
| 最抵嘅定位 | ✅ **賣「保持最新」,唔好賣「抓一次」** |

**35–45% 仍然係我哋傾過所有方法之中最高嗰個。** 但你要知你買緊嘅係一張咩彩票。

而且最重要嗰句再講一次：

> **初稿正在變成免費。承擔責任冇。**
