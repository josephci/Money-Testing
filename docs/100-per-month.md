# 零本金做到月入 US$100（容許半自動）

前提：**冇本金、肯落手做、識寫 code。**

呢份係主計劃。`ideas.md` 嗰 16 個方法有一半喺呢個目標下應該直接 skip，下面會講邊啲。

## 一、先計清楚條數

$100/月唔係一個大數，關鍵係你揀邊個價位。Stripe 收 2.9% + $0.30：

### 訂閱制

| 月費 | 實收/客 | 需要客數 |
|---|---|---|
| $9 | $8.44 | **12 個** |
| $19 | $18.15 | **6 個** |
| $29 | $27.86 | **4 個** |
| $49 | $47.28 | **3 個** |
| $99 | $95.83 | **2 個** |

### 一次性 / 服務

| 單價 | 每月要賣 |
|---|---|
| $29 產品 | 4 件 |
| $49 產品 | 3 件 |
| $99 產品 | **1–2 件** |
| $100 服務 | **1 單** |

### 廣告（作對比）

AdSense RPM（每千次瀏覽收入）通常 $2–10，睇題材同讀者地區：

| RPM | 需要月瀏覽量 |
|---|---|
| $2 | 50,000 |
| $5 | 20,000 |
| $10 | 10,000 |

**睇到未** —— 廣告要幾萬人流，直接收費只要 **3–4 個客**。呢個就係點解下面成份文都唔會叫你行廣告路線。

## 二、三個決定成敗嘅策略

### 1. 加價 ＞ 加量

由 $10 做到 $100，最蠢嘅做法係「搵多 10 倍客」，最聰明嘅做法係「同一批客收貴啲」。

**$29/月搵 4 個客，通常易過 $9/月搵 12 個客。** 唔係開玩笑 —— 你要做嘅推廣工作少咗三分二，而拒絕率唔會高好多。

### 2. 賣俾公司，唔好賣俾個人

| | 個人用戶 | 公司/自由工作者 |
|---|---|---|
| $29/月 嘅反應 | 「咁貴？」諗三日 | 唔使批就簽得，一餐飯錢 |
| 買嘢動機 | 慳錢 / 好玩 | 慳時間 / 賺錢 / 避免出事 |
| 客戶流失 | 高，兩個月就 cancel | 低，用慣咗唔會轉 |
| 客服負擔 | 大 | 細 |

**價格甜蜜點：US$20–50/月。** 呢個範圍公司唔使審批，但已經夠你 3–4 個客就達標。

### 3. 先賣後做，唔好先做後賣

最大陷阱：花三個月砌完一個好靚嘅產品，出街發現冇人要。

**正確次序：**

```
搵到有人已經喺度俾錢解決嘅問題
        ↓
用人手幫佢做，即刻收錢          ← 呢度已經有 $100/月
        ↓
寫 script 自動化「你自己」嘅工序  ← 收入唔變，你嘅時間減 80%
        ↓
變成客人自助嘅產品              ← 新客唔再佔你時間
```

你話「半自動都得」，所以呢條路啱晒你。**第一步就已經達到目標**，之後每一步都係喺已經有收入嘅情況下慢慢優化 —— 零風險。

## 三、點樣搵到「有人肯俾錢」嘅題目

唔好憑空諗 idea。去有人**已經喺度俾緊錢**嘅地方睇。

### 方法 A：Fiverr / Upwork 當需求資料庫（最快最準）

呢個係最被低估嘅方法。Fiverr 上面每個 gig 都顯示**已完成訂單數同評價數**。

1. 搵 `automation`、`web scraping`、`data entry`、`report`、`excel` 之類嘅類別
2. 搵嗰啲賣 $30–80、有幾百個 review 嘅 gig
3. **有幾百個 review = 已證實有持續需求，唔使你估**
4. 你可以：(a) 直接開 gig 做同樣嘢，(b) 睇下嗰啲賣家點解可以做咁多單 —— 佢哋一定有自動化，你可以做得更自動

呢個方法嘅價值：**你唔使賭需求，需求已經擺喺你面前有數據。**

### 方法 B：搵「重複性怨言」

去目標客群出沒嘅地方，搜以下字眼：

- `"is there a tool that"` / `"有冇工具可以"`
- `"how do I automate"` / `"每個星期都要手動"`
- `"I do this manually every"` / `"好煩" + 某個工作流程`

**同一個抱怨見到 3 次以上 = 真需求。**

去邊度搵：Reddit 行業版、專業 Discord / Facebook group、行業論壇、X。

### 方法 C：睇大工具嘅差評

去 G2 / Capterra / Chrome Web Store 睇熱門工具嘅 **1–2 星評價**。

差評即係「我肯俾錢，但你做唔到我要嗰樣嘢」—— 呢啲人係現成嘅、已證實會俾錢嘅客。

### 篩選準則（四個都要中）

1. ✅ 目標用戶係**靠呢件事搵錢**嘅人（唔係興趣用戶）
2. ✅ 你講得出佢哋今日喺網上邊度出沒
3. ✅ 問題係**重複發生**嘅（→ 可以收月費），唔係一次性
4. ✅ 你可以喺一個週末用**人手**幫一個人做一次

## 四、值得做嘅題目類型

以下全部都係零本金、對 coder 有優勢、而且天然係 recurring：

### ⭐ 監察 + 通知類（最推薦）

幫人盯住某樣會變嘅嘢，一有變就通知。

例：競爭對手改價、某類職位新招聘、政府/監管網站更新、某平台上架新貨、關鍵字排名、某公司招標公告。

- **點解好**：問題天然重複 → 天然收月費；技術上唔難；你唔使做內容
- 定價 $19–39/月，**4–5 個客達標**

### ⭐ 定期報告類

客俾數據（或者你去攞），你每月自動出一份靚報告 / dashboard。

- **點解好**：好啱由人手開始 —— 頭幾個月你自己整都得，一個月得幾個鐘
- 定價 $29–49/月

### ⭐ 開發者工具 / Boilerplate

賣 starter kit、UI 元件、CLI 工具、模板。**開發者係最肯為慳時間俾錢嘅一群。**

- 定價 $49–99 一次性 → **一個月賣 1–2 件達標**
- ✅ 你嘅客同你講同一種語言，推廣渠道你本身就識（GitHub、HN、dev 社群）

### ⭐ 針對某個熱門 SaaS 嘅外掛 / 擴充

揀一個有幾十萬用戶嘅工具（Notion、Shopify、Figma、Slack、某 CRM…），做佢**缺咗**嘅嗰個功能。

- ✅ **唔使自己搵客** —— 佢哋嘅 marketplace / 社群就係你嘅流量
- ⚠️ 風險：官方可能自己做埋，或者改 API 整死你。唔好 all-in

### ⭐ 生產化服務（Productized Service）

固定價錢、固定範圍、固定交付嘅服務。例：「$99 幫你做一次網站速度優化報告」。

- ✅ **最快見到第一蚊**，通常兩個禮拜內
- ✅ 一個月做 1 單就達標
- ❌ 唔會自動增長 —— 但係最好嘅起步，因為你會學到真實需求

### 🟡 可以考慮

- **付費目錄站** — 收 listing 費 $20–50，半自動，但要先養到流量
- **窄領域 newsletter 賣贊助** — 大約 500–1,000 個精準訂閱就賣得 $50–100 一個 slot；要持續寫
- **高佣金 affiliate** — hosting / B2B SaaS 一單就 $50–100，但要 SEO 排到名，慢

### ❌ 呢個目標下唔好做

| 唔好做 | 原因 |
|---|---|
| AdSense 內容站 | 要幾萬人流換 $100，同樣努力做產品可以賺 10 倍 |
| Print on Demand / Stock 素材 | 單價太低，$100/月要賣幾百件 |
| Dropshipping | 要本金、要廣告費、係營銷遊戲唔係技術遊戲 |
| iOS App | Apple 開發者 $99/年，未賺已經蝕 |
| 手機掛機 / 問卷 / 頻寬分享 | 數學上永遠去唔到 $100 |
| Crypto | 冇本金就唔關你事 |

## 五、流量點嚟（真正嘅瓶頸）

**產品做得出係最易嗰部分。90% 嘅人死喺呢一步。**

按「見效速度」排：

### 1. 有現成買家嘅平台（最快）

Fiverr、Upwork、RapidAPI、Chrome Web Store、Notion/Figma/Shopify marketplace、Gumroad discover。

- ✅ **買家已經喺度**，唔使你教育市場
- ❌ 要俾抽成（15–20%）
- 💡 起步階段呢個抽成 **值得俾** —— 你買嘅係「唔使自己搵客」

### 2. 一次性目錄提交（低成本長尾）

Product Hunt、Show HN、BetaList、AlternativeTo、SaaS 目錄站（有幾百個，好多免費）。

- 花一個週末提交幾十個，之後長期慢慢有零星流量同 backlink

### 3. 社群（要真誠）

Reddit、Discord、Facebook group、行業論壇。

- ⚠️ **先睇清楚每個社群嘅自我宣傳規則。** 一入去硬銷 = 即刻俾人 ban，仲要害咗個品牌
- ✅ 正確做法：真心答問題，答到啱位先提「我啱啱做咗個嘢可能幫到你」

### 4. 精準冷聯絡（B2B 最有效但最唔 scale）

搵 50 個真係有呢個問題嘅公司，逐個寫一封**針對佢哋**嘅短 email。

- 正常轉化率 2–5% → 50 封換 1–2 個客 → **可能一次就達標**
- ⚠️ 一定要真係逐間睇過先寫，唔好群發。群發違反好多地方嘅反垃圾郵件法，而且效果差

### 5. SEO（最慢但最持久）

針對「有購買意圖」嘅長尾字：`XX alternative`、`如何自動化 XX`、`XX vs YY`。

- 3–12 個月見效，但排到之後長期免費送客上門

## 六、90 日計劃

假設你一星期投入 **5–10 個鐘**。

### Day 1–14：搵題目（唔准寫 code）

- [ ] 用方法 A/B/C 開一張 list，儲 10 個候選
- [ ] 每個候選寫低：客係邊個、佢今日點解決、佢喺邊出沒、你收得幾錢
- [ ] 用四項準則篩到剩 2 個
- [ ] **同至少 5 個真實目標用戶傾過**（Reddit DM、社群、Fiverr 買家都得）

> 🚨 最常見嘅失敗：跳過呢兩個禮拜直接開始寫 code。忍住。

### Day 15–30：未做住就賣

- [ ] 用最貴嗰個可行價錢定價（$29–49/月 或 $99 一次性）
- [ ] 整一頁 landing page（講問題、講方案、講價錢、一個按鈕）
- [ ] 上 Fiverr / Upwork 開 gig，**或者**直接接 1–2 個人手客
- [ ] **目標：收到第一蚊。人手交付完全 OK。**

### Day 31–60：交付 + 自動化你自己

- [ ] 人手服務你頭幾個客，記低每一步
- [ ] 邊一步最耗時就寫 script 自動化嗰步
- [ ] 目標：由「每單 3 個鐘」變「每單 20 分鐘」
- [ ] 收入應該喺 **$50–150/月** 之間

### Day 61–90：自助化 + 推廣

- [ ] 客人可以自己註冊、自己攞結果，唔使經你手
- [ ] 駁 Stripe / Lemon Squeezy 自動收費
- [ ] 一個週末提交晒所有目錄站
- [ ] 揀一條長期渠道（SEO 或者社群）持續做

**90 日後合理結果：$100–200/月，每月佔你 2–5 個鐘。**

## 七、老實講吓期望

### 時間線

| 里程碑 | 合理時間 |
|---|---|
| 第一個俾錢嘅客 | 3–8 星期 |
| $100/月 | **3–6 個月** |
| 每月只需 2–3 個鐘維護 | 6–9 個月 |

如果有人話你 30 日零本金做到 $100/月被動收入，佢係想賣課程俾你。

### 要有心理準備

- **頭一兩個 idea 大機會失敗。** 呢個唔係你唔得，係正常流程。預留 2–3 次嘗試嘅耐性
- **最難嘅係 $0 → 第一個客**，唔係 $10 → $100。第一個客之後，第 2 到 4 個會快好多
- **每個月檢查一次時薪。** 如果 $100/月要你做 20 個鐘，咁係 $5/小時 —— 唔係被動收入，係廉價兼職。要即刻自動化或者加價

### 三個致命錯誤

1. **未出街就無限加功能** —— 冇人用嘅完美產品，價值係零
2. **定價太平** —— $5/月要 20 個客，$29/月要 4 個。定平價唔會令你易賣好多，只會令你辛苦 5 倍
3. **死撐一個冇人要嘅 idea** —— 落咗 60 個鐘都好，冇人俾錢就斬。沉沒成本唔係繼續嘅理由

## 八、如果你想聽一個具體建議

**做「監察 + 通知」類，賣俾一個你熟嘅行業，收 $29/月。**

原因：

- 技術上你一定做得到（定時抓取 + 比對 + 發通知）
- 天然係 recurring，客一裝就唔會 cancel
- 問題重複發生 → 客肯付月費而唔係一次性
- 免費 tier 就跑得起（Cloudflare Workers cron / GitHub Actions 定時任務）
- **4 個客就達標**

第一步唔係寫 code，係揀行業，然後去嗰個行業嘅社群蹲一個禮拜，睇下佢哋成日抱怨要盯住咩。

⚠️ 抓取資料前睇清楚對方嘅服務條款同 `robots.txt`，用官方 API 有得用就用官方。
