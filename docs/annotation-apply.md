# ⭐ 最重要嘅發現：你識廣東話,係一個受薪資產

我本來以為地區限制會封死你（好多呢類平台只收美/英/加/澳）。查落唔係咁,而且情況比預期好好多。

**DataAnnotation 有兩個專門招中文人嘅頁：**

- `dataannotation.tech/hongkong-bilingual` ← **香港專頁**
- `dataannotation.tech/chinese-bilingual-en`

LinkedIn 亦有佢哋喺 **Hong Kong SAR** 招 AI Trainer 嘅招聘。

## 而中文/廣東話係加價項目

| | 時薪 |
|---|---|
| 一般英文標註 | $20–40 |
| **中文（含廣東話）** | **$30–75** |
| 多語言項目一般 | $20–50+ |

查到嘅原文話明：**廣東話任務需要識廣東話特有詞彙、同普通話唔同嘅文法、同埋粵語書面口語傳統** —— 包括翻譯評估、文化語境判斷、字形變體核對。

**呢啲嘢 AI 做唔到,而識嘅人少。**

## 換算你嘅目標

> **$50/月 ÷ $35/小時 ≈ 每月做 1.5 個鐘。**

比我上次估嘅 2 個鐘仲好。

# ⭐ 第二個關鍵：走語言線,唔好走 coding 線

呢點好重要,因為佢決定你入唔入到。

DataAnnotation 嘅入門測試有幾條線。**Coding 線**測嘅係：

- 揀出 AI 生成 code 入面嘅 bug 同 edge case
- 寫出處理得到邊界情況嘅正確 code

**你講過「識少少,由零寫唔到完整嘢」—— 呢條線對你唔利。**

**但語言線唔使寫 code。** 佢測嘅係：

- 跟足一份好長好細嘅評分準則
- 判斷兩個回答邊個好、點解
- 用清楚嘅文字解釋你嘅判斷
- 廣東話/中文嘅語感同文化語境

**你嘅資格係你識廣東話,唔係你識寫 code。** 由呢度入。

# 建議：一次過申請三個

因為**拒絕係靜默嘅**（下面會講),唔好淨係申請一個然後乾等。

```
1. DataAnnotation（香港雙語頁）   ← 主攻,最抵
2. Appen                          ← 保底,最易入
3. Toloka / Mindrift              ← 保底
```

三個都申請,總時間約 2 個鐘。邊個先批就做邊個。

# DataAnnotation 申請流程（主攻嗰個）

## 你要準備

| | |
|---|---|
| 政府身份證明 | **兩張相**（身份證正反面） |
| 基本資料 | 姓名、地址 |
| 收款 | Stripe 支援嘅方式（佢喺約 46 個 Stripe 國家運作） |
| 費用 | **零**。任何叫你俾錢嘅都係假網站 |

## 流程

```
喺 hongkong-bilingual 或 chinese-bilingual 頁申請
        ↓
填基本資料 + 上載身份證
        ↓
Starter Assessment（約 1 個鐘,無償）
        ↓
等 —— 幾日到 2-3 個星期
        ↓
批咗 → 開始接任務
```

**整個過程由申請到第一個任務,通常 1–3 個星期。**

# ⚠️ Starter Assessment —— 一次機會,冇得重考

呢個係最重要嘅一段,慢慢睇。

## 佢實際測緊咩

| 佢想睇 | 意思 |
|---|---|
| **跟足一份好長嘅評分準則** | 唔係測你叻唔叻,係測你肯唔肯逐點跟 |
| 判斷準確 | 兩個 AI 答案邊個好,點解 |
| **解釋得清楚** | 用平實文字講你嘅理由 |
| **前後一致** | 十題用同一套標準,唔可以前鬆後緊 |

## 五個實際建議

**1. 唔好趕。**
DataAnnotation 明文講佢哋睇**仔細同準確,唔係速度**。估計一個鐘,你用兩個鐘冇問題。

**2. 逐點對返份準則。**
最多人衰喺呢度 —— 睇完準則就憑感覺答。**答完每題,返去對返份準則逐點打勾。**

**3. 解釋要具體。**
❌「Response A 好啲,寫得清楚啲」
✅「Response A 好啲,因為佢直接答咗個問題先至補充背景,而 Response B 頭兩段都係鋪陳,而且第三點同準則第 4 條要求嘅格式唔符。」

**4. 前後一致。**
如果你第 1 題因為「太長」扣分,第 7 題同樣長就要同樣扣。**佢哋就係喺度睇你穩唔穩定。**

**5. ⚠️ 唔好用 AI 幫你做份測試。**

呢點要特別講：

- 份測試本身就係**測你捉唔捉到 AI 嘅錯誤** —— 用 AI 做等於自相矛盾
- 平台有偵測。之前有研究發現三分一以上 MTurk worker 用 AI,搞到資料質素崩潰,而家全行都收緊
- 一次機會,冇得重考

**佢請你,就係因為你係人。**

# 三個要有心理準備嘅事

### 1. 拒絕係靜默嘅

**唔會有拒絕信。** 兩個星期冇消息,通常就係唔取錄。

呢個係點解要**同時申請三個平台**。

### 2. 實際時薪低過標價

標住 $35/小時,但**搵任務、篩選、無償測試**嗰啲時間唔計錢。

實際可能係 $20–25。**即使咁,$50/月 都只係 2–2.5 個鐘。**

### 3. 任務唔係長期穩定

呢行有「任務荒」—— 項目做完就冇,要等下一個。

> Clickworker 就係因為任務荒 + 大量封號,Trustpilot 由 4 分以上跌到 2.6。

**所以：唔好當佢係一份工。當佢係「想要嗰陣攞到嘅現金」。**

# 入到之後 —— 點寫解釋
