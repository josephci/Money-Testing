## $100/月 版本 — 一分鐘結論

**由 $10 到 $100 唔係搵多 10 倍客，係加價同揀啱客。**

- $9/月 → 要 12 個客
- **$29/月 → 只要 4 個客**

三個決定成敗嘅嘢：

1. **加價 ＞ 加量** — $29/月搵 4 個客，易過 $9/月搵 12 個
2. **賣俾公司，唔好賣俾個人** — 公司唔會為 $29 諗三日
3. **先賣後做** — 用人手交付、即刻收錢，之後先自動化。你話半自動得，咁第一步就已經達標

**推薦題目**：「監察 + 通知」服務，賣俾一個你熟嘅行業，$29/月，4 個客達標。免費 tier 就跑得起（Cloudflare Workers cron / GitHub Actions）。

**合理時間線**：第一個付費客 3–8 星期，$100/月 3–6 個月。

## 一分鐘結論

**「自動」呢兩個字係關鍵。** 世上真正接近全自動嘅收入，得兩類：

1. **資本生息** — 有本金，放喺生息工具，之後零操作。
2. **一次性數碼產品** — 做一次，可以無限複製賣，邊際成本近乎零。

其他所有所謂「被動收入」（YouTube、blog、代購、轉售）都係**半自動**：要持續出內容、覆客、更新，停手就冇收入。

### 三條推薦路線

| 路線 | 需要 | 幾耐見錢 | 自動化程度 |
|---|---|---|---|
| **A. 買定離手** — 本金放高息戶口 / 貨幣基金 | 約 US$2,500–3,500 本金 | 即刻（下個月起） | ⭐⭐⭐⭐⭐ 真·全自動 |
| **B. 賣細數碼產品** — 模板 / 工具 / 小 SaaS | US$0 本金 + 10–30 個鐘 | 1–3 個月 | ⭐⭐⭐⭐ 做完後低維護 |
| **C. 廣告 / Affiliate** — 細 app、SEO 文、插件 | US$0 本金 + 20–60 個鐘 | 3–12 個月 | ⭐⭐⭐ 要餵流量 |

**如果你有本金** → 揀 A，今個禮拜搞掂，之後唔使再諗。
**如果你冇本金但識寫 code**（你有 GitHub，應該識）→ 揀 B，$10/月即係**得 4 個客俾你 $3/月**，或者**一個月賣出 2 件 $6 嘅嘢**。呢個門檻低到誇張。
**如果兩樣都想** → A 保底，B 當有趣 side project。

### 最重要嗰個數字

$10/月唔係「賺 $10」，係「**收到手 $10**」。好多平台有提款門檻同手續費，會令你「賺咗但攞唔到」：

- Google AdSense/AdMob：夠 **US$100** 先俾你提款 → $10/月即係要儲 10 個月
- Stripe 收 2.9% + $0.30 → 你賣 $3 嘅嘢，實收 $2.61（食咗 13%）
- 賣 1 件 $12 嘅嘢 ＞ 賣 4 件 $3 嘅嘢（同樣收入，手續費少一半）

詳情見 [`docs/pitfalls.md`](docs/pitfalls.md)。
